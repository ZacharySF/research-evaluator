Risks found while scouting

Synthetic sources are not evidence

SIM-S1–SIM-S8 are invented no-link labels, not real citations or claims about existing software.

Check: Replace the entire scenario with actual located primary sources and receipts before using it for a real decision.

Constraints can disappear in a pivot

Weakening offline revocation to expiry changes the guarantee; a useful fallback cannot silently become the original promise.

Check: Keep the original constraint visible and obtain any required user authorization before changing it.

Two high sections are not a pass

R7's synthetic Novelty 96 and Impressiveness 95 exceed 94, but Feasibility 62 fails 80; Evidence quality is 85/80. Its highest total is display-only.

Check: Require every configured section and every hard constraint using the actual report and mode-appropriate evidence; never promote an atlas summary into approval.
